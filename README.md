# Stemify

เว็บแยกเสียงเพลงด้วย Demucs `htdemucs_6s` รองรับการนำเข้าไฟล์เสียง/วิดีโอและลิงก์ YouTube ที่ผู้ใช้มีสิทธิ์ใช้งาน แยกและประมวลผลต่อเป็น 9 แทร็ก ได้แก่ ร้องนำ แบ็กกิ้งโวคอล กีตาร์โซโล่ กีตาร์คอร์ด เบส เปียโน/คีย์บอร์ด กลอง เครื่องสี และเครื่องเป่าทองเหลือง จากนั้นเล่น ปรับระดับ Mute/Solo ตรวจจับคีย์ เปลี่ยนคีย์ ±12 semitones กรอเพลงอิสระ และเรนเดอร์มิกซ์ใหม่ได้จริง

## เปิดใช้งาน

```bash
npm start
```

เปิด `http://localhost:3000` จากเครื่องเดียวกัน หรือ `http://IP-ของเครื่อง:3000` จากโทรศัพท์/แท็บเล็ตใน Wi-Fi เดียวกัน

ไฟล์งานจะถูกเก็บใน `data/outputs` การแยกเพลงใช้ CPU/GPU และเวลาที่ใช้ขึ้นกับความยาวเพลงและประสิทธิภาพเครื่อง จำกัดไฟล์ 250 MB และความยาว 15 นาที

## ระบบที่ติดตั้งแล้ว

- Express API และระบบอัปโหลด
- `yt-dlp` สำหรับนำเข้าสื่อที่ได้รับอนุญาต
- FFmpeg สำหรับเข้ารหัสและเรนเดอร์มิกซ์
- Demucs 6-source model สำหรับแยก stem
- Web Audio mixer และ Media Session สำหรับการควบคุมบนอุปกรณ์พกพา
- Key detection แบบ chroma analysis และ pitch shifting แบบรักษาความยาวเพลง

หมายเหตุ: เบราว์เซอร์มือถือกำหนดให้ผู้ใช้กดเล่นเองอย่างน้อยหนึ่งครั้ง และระบบปฏิบัติการอาจหยุดเว็บที่อยู่เบื้องหลังเมื่อใช้โหมดประหยัดพลังงาน
